# Contributing to Stock Market Intelligence Data Pipeline

Thank you for contributing to this project. This file explains the contribution process and standards.

## How to contribute

1. Fork the repository or create a branch from `main`/`master`.
2. Make changes in a feature branch using a descriptive name, e.g. `feature/add-dataflow-config`.
3. Install dependencies and run the project locally before submitting a PR.
4. Create a pull request with a clear description of what changed and why.
5. Keep commits small and focused.

## Coding standards

- Use Python 3.11+.
- Keep code readable and modular.
- Add comments for complex logic.
- Follow the existing project structure.

## Branching and pull requests

- Branch from `master`.
- Open pull requests against `master`.
- Use descriptive PR titles.
- Describe any dependencies or setup required to validate the change.

## Issue reporting

Use issue templates for bugs and feature requests.
